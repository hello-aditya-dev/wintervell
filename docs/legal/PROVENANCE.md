# WinterVell — Provenance

**Date:** 2025-08-03
**Branch:** agent/wintervell-phase-00-baseline

## Purpose

This document records the origin of all code, assets, and intellectual property in the WinterVell repository. It tracks which code was written specifically for WinterVell, which was derived from other sources, and which was generated by AI tools.

## Code Origin

### Original WinterVell Code

All code in the `src/` directory was written specifically for the WinterVell project by AI-assisted development (Z.ai). This includes:

- Public site components (`src/components/site/`)
- App shell components (`src/components/app-shell/`)
- Shared components (`src/components/shared/`)
- Product route pages (`src/app/app/`)
- Public route pages (`src/app/product/`, etc.)
- Demo data architecture (`src/demo/`)
- Commercial configuration (`src/config/commercial.ts`)
- API routes (`src/app/api/`)
- Design system (`src/app/globals.css`)
- Root layout (`src/app/layout.tsx`)

### Cloudsun Reference

The Cloudsun repository (`github.com/witejackel-eng/cloudsun`) belongs to the same owner and may be inspected for reusable CRM architecture and code patterns. As of Phase 0:

- **No code has been copied from Cloudsun** into the WinterVell repository
- Cloudsun may be referenced in future phases for CRM patterns
- Any code reused from Cloudsun must be recorded in this document
- Cloudsun must not be modified
- WinterVell is a separate product, repository, deployment, and database

### AI-Assisted Code

All code in the WinterVell repository was generated with AI assistance (Z.ai). This means:

- AI tools wrote the code based on human specifications
- No human wrote the code directly
- The code has been reviewed and tested by AI agents
- The code should be reviewed by a qualified human before production use

### Third-Party Libraries

All third-party libraries are listed in `package.json` and documented in `THIRD_PARTY_NOTICES.md`. No third-party code has been copied directly into the source tree (except shadcn/ui components, which are designed to be copied).
